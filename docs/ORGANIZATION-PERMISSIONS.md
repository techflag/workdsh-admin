# 组织与权限管理


组织架构使用部门树、成员表格与添加/编辑抽屉。支持部门增改删、最多十层与防循环；有子部门或成员的部门不能删除。成员支持姓名、邮箱、管理员设置的登录用户名、主部门、工号、职位、筛选、批量启停与调整部门。所有写入在Java后端验证当前成员组织和管理员权限。所有者不能在这里降权/停用，只有所有者可管理管理员角色。

通讯录支持全组织或同部门，同部门包含双方都未分配部门的情况、不包含子部门；该策略作用于同事目录和新的协作发送，猜成员ID不能绕过。已分享资料只对参与双方可见。组织管理员按已确认授权只读查看本组织成员会话正文，每次记录审计，不开放会话编辑或Agent执行。


普通成员只有自己的会话与授权成果；组织+成员范围授权、凭据和原生日志由现行Java服务检查归属。数据库部署差异见ENTERPRISE-DATABASES.md。SSO、席位、自定义跨部门角色、邀请邮件、手机号登录和批量导入尚未实现。
